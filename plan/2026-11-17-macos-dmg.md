# macOS-only сборка и DMG

> **For agentic workers:** выполнять по шагам с проверкой после каждого. Пункты `Progress`
> и `Outcomes` заполнять по ходу.

**Goal:** форк собирает и публикует один артефакт — `yamusic-rs-<версия>.dmg` с universal
`.app`; Windows и Linux из CI и релиза убраны.

**Architecture:** `tools/make_app.sh` по-прежнему собирает `.app`, новый `tools/make_dmg.sh`
упаковывает готовый бандл через системный `hdiutil` (HFS+, UDZO) в том с `.app` и симлинком
`/Applications`. CI оставляет одну джобу `macos`, которая гоняет clippy и тесты (иначе
проверки исчезнут вместе с удаляемыми джобами), собирает universal `.app`, делает dmg и
отдаёт его в `release`.

## Global Constraints

- Версия в `Cargo.toml` должна совпадать с тегом `vX.Y.Z`.
- Новых зависимостей нет: только `hdiutil`, `ln`, `cp` из системы.
- Имя файла — латиницей: `yamusic-rs-<версия>.dmg`; имя тома — «Яндекс Музыка RS».
- Ad-hoc подпись и предупреждение Gatekeeper остаются как есть (Apple-сертификата нет).
- Комментарии и сообщения скриптов — по-русски, как в репозитории.

### Task 1: `tools/make_dmg.sh`

**Files:** create `tools/make_dmg.sh`.

**Interfaces:** consumes `target/<profile>/yamusic-rs.app` (его делает `tools/make_app.sh`);
produces `target/<profile>/yamusic-rs-<версия>.dmg`.

- [ ] **Step 1: написать скрипт**

```bash
#!/bin/bash
# Собирает .dmg из готового .app: том с приложением и симлинком /Applications,
# чтобы установка была перетаскиванием. Сборку .app делает tools/make_app.sh.
# Использование: tools/make_dmg.sh [--debug] (по умолчанию release).
set -euo pipefail
cd "$(dirname "$0")/.."

PROFILE=release
if [ "${1:-}" = "--debug" ]; then
  PROFILE=debug
fi

VERSION=$(grep -m1 '^version' Cargo.toml | cut -d'"' -f2)
APP="target/$PROFILE/yamusic-rs.app"
DMG="target/$PROFILE/yamusic-rs-$VERSION.dmg"
STAGE=$(mktemp -d)
trap 'rm -rf "$STAGE"' EXIT

if [ ! -d "$APP" ]; then
  echo "Нет $APP — сначала соберите его: tools/make_app.sh" >&2
  exit 1
fi

cp -R "$APP" "$STAGE/"
ln -s /Applications "$STAGE/Applications"
rm -f "$DMG"
hdiutil create -volname "Яндекс Музыка RS" -srcfolder "$STAGE" \
  -fs HFS+ -format UDZO -ov -quiet "$DMG"
echo "Готово: $DMG"
```

- [ ] **Step 2: собрать и проверить том**

```bash
tools/make_app.sh
tools/make_dmg.sh
hdiutil attach target/release/yamusic-rs-1.1.3.dmg -nobrowse -readonly
ls -l "/Volumes/Яндекс Музыка RS"
test -L "/Volumes/Яндекс Музыка RS/Applications"
lipo -info "/Volumes/Яндекс Музыка RS/yamusic-rs.app/Contents/MacOS/yamusic-rs"
hdiutil detach "/Volumes/Яндекс Музыка RS"
```

Ожидается: `.app`, симлинк `Applications -> /Applications`, жирный бинарник `x86_64 arm64`.

## Surprises & Discoveries

## Decision Log

- DMG без оформления (фон, стрелка): `hdiutil` без AppleScript и Homebrew-зависимостей.
- Проверки clippy/test переезжают в macOS-джобу: иначе после удаления Windows/Linux CI
  перестаёт их запускать.
- `tools/make_dmg.sh` отдельным файлом, а не флагом `make_app.sh`: как `tools/appimage.sh`,
  один шаг — одна ответственность.
- Релизы собираются локально (`tools/release.sh`) и CI их не публикует: macOS-раннеры
  у GitHub бывают недоступны часами, а релиз из чистой ветки на маке воспроизводим.
